# Student Grade Tracker
## Internship Project

Developed as part of the **CodeAlpha Java Programming Internship – September 2026**.

A Java-based Student Grade Tracker that manages student marks, calculates averages, grades, results, rankings, and generates individual report cards.

## Features

- Add multiple students
- Add multiple subjects
- Enter subject-wise marks
- Marks validation (0–100)
- Calculate average marks
- Find highest and lowest marks
- Pass/Fail result
- Automatic grade calculation
- Rank students based on average
- Find class topper
- Display final class summary
- Search students by name
- Generate detailed student report card

## Technologies Used

- Java
- Scanner
- ArrayList
- Object-Oriented Programming concepts
- Git & GitHub

## How It Works

1. Enter the number of students.
2. Enter the number of subjects.
3. Enter subject names.
4. Enter each student's name and marks.
5. The program calculates the average, highest, lowest, result, and grade.
6. Students are ranked according to their average marks.
7. The class topper and final class summary are displayed.
8. Search for any student to view their complete report card.

## Grade System

| Average Marks | Grade |
|---|---|
| 75 and above | A |
| 65–74 | B |
| 35–64 | C |
| Below 35 / Failed | F |

## Project Purpose

This project was developed to practice Java programming, ArrayList, loops, conditions, searching, sorting/ranking logic, and handling student data.
